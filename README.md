An interactive Sales Performance & Revenue Analysis Dashboard built in Microsoft Excel to analyze sales data and generate meaningful business insights. 
It provides a clear view of revenue, sales performance, product and category trends, with interactive slicers and visualizations for easy analysis and decision-making.

🛠️ Tools:
Microsoft Excel
Pivot Tables & Charts
Slicers
Data Cleaning & Analysis

📊 Features:
Revenue & Sales KPIs
Product & Category Analysis
Interactive Filters
Sales Performance Insights
